# Corrected AMAM-128 manuscript

`AMAM_128_corrected.tex` is the complete corrected source derived from the
attached manuscript. Its figure paths assume compilation from this `paper/`
directory and resolve to the repository's `assets/` and `repro/` directories.

The attachment and repository do not contain `neurips_2023.sty` or `refs.bib`.
Place those two existing project files on the TeX search path (or beside the
manuscript) before compiling, for example:

```sh
cd paper
latexmk -pdf AMAM_128_corrected.tex
```

The corrected benchmark-gap figure is generated by
`../repro/benchmark/plot_benchmark_gap_figure.py` from the fixed-seed
classical/foundation tables and the five-run deep mIoU summary.
